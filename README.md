# 五子棋小游戏 Gomoku

一个极简的五子棋小项目，包含**控制台版**和**网页版**两种玩法，零依赖、开箱即用。

## 玩法

- 棋盘 15×15，黑白双方轮流落子
- 任意一方在横、竖、斜方向上先连成五子即获胜

## 版本

| 文件 | 说明 | 运行方式 |
|------|------|----------|
| `Gomoku.java` | 控制台版（Java） | `javac Gomoku.java && java Gomoku` |
| `index.html` + `gomoku.js` | 网页版 | 浏览器直接打开 `index.html` |
| `HelloWorld.java` | 网页版启动小助手（可选） | `javac HelloWorld.java && java HelloWorld` |

## 说明

这是一个学习用途的练习项目，代码结构简单，适合初学 Java / JavaScript 的朋友参考。
